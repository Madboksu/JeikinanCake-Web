# Project Web UMKM: Jenkeinan's Cake

Repositori ini berisi kode sumber untuk platform *company profile* dan katalog produk digital berbasis web milik UMKM Jeikinan Cake. Sistem ini dirancang untuk memberikan pengalaman pengguna yang interaktif dan elegan dalam menampilkan produk roti dan kue unggulan.

## 🚀 Fitur Utama

* **Antarmuka Responsif:** *Landing Page* modern dengan dukungan navigasi *smooth scroll* yang mulus.
* **Standar MVC:** Penerapan arsitektur MVC (Model-View-Controller) menggunakan *framework backend* CodeIgniter 4 yang tangguh.

## 🛠️ Teknologi yang Digunakan

| Komponen | Teknologi Utama |
| :--- | :--- |
| **Backend** | PHP, CodeIgniter 4 |
| **Frontend** | HTML5, Vanilla CSS3 |
| **Database** | MySQL (`jeikinancake_db`) |
| **Lingkungan** | WSL (Ubuntu), PHP Spark Serve |
